# slide-style.md — 분석형 덱 스타일 규격 v0.1

> 고객 지정 템플릿이 없을 때의 기본값. 원본 덱을 직접 열어 확인하지 못했다면 「원본과 같은 색·폰트·간격을 재현했다」고 말하지 않는다.

## 1. 화면 기본값

| 요소 | 규격 |
|---|---|
| 바탕 | 흰색 |
| 제목·구분선 | 빨강 `#C00000` bold, 번호 접두 가능(`N. {주제} …`) |
| 헤드라인(키메시지) | 검정, 1~2문장 |
| 본문 | 검정·회색(`#595959`) |
| 보조 강조 | 적갈색 `#843C0C` (불릿·2순위 강조) |
| 라벨 박스 | 회색 `#D9D9D9` |
| 하단 결론줄 | `☞` 한 줄, 본문 블록 하단에만 (헤드라인에는 쓰지 않음) |

## 2. 헤드라인 문형

- 종결은 명사형 `~음 / ~임`. `~입니다/~합니다` 존댓말 금지(예외: 비주얼 요약 하단 결론 띠).
- 길이는 90~130자, 1문장 또는 2문장.
- 2문장일 때 골격: **[1문] 무엇이 어떤 구조인가(사실·구조) → [2문] 그래서 어떻게 봐야 하는가(판정·재정의·함의)**.
- 사실은 `~음/~임`, 전망은 `~것임/~전망임`, 판정은 `~봐야 함`, 추정은 `~로 해석됨/~가능함`. 사실과 의견을 어미로 구분한다.
- 재정의 수사를 쓴다: `A가 아니라 B`, `A이자 B`, `A보다는 B`, 대조쌍 이름 붙이기.
- 인사이트는 「무엇이 바뀜」이 아니라 **「무엇이 무엇으로 바뀜」**을 이름으로 잡는다(이동에 이름 붙이기 / 전제의 붕괴 지목 / 주어·책임의 이동).
- 과장 형용사(혁명적·압도적·최고의) 금지. 수치와 구조로 말한다.

## 3. 구조화

모든 장에 축·단계·분면 중 하나를 넣는다.
- 2축, 3분류, 4분면, 흐름 화살표(`A → B → C`), 문장 안 ①②③.
- 수치에는 비교축(전년 대비·경쟁사 대비·시장 평균)을 붙인다.

## 4. 표기

- `「 」`는 자기가 세운 개념·명제의 핵심 명사만 감싼다(조사는 밖).
- `' '`는 통념·기존 용어를 거리 두고 인용할 때.
- 첫 등장은 `한글(English;약어)` 병기, 재등장은 한글 또는 약어만. 모든 단어를 기계적으로 영문 병기하지 않는다.
- 연도는 백틱 축약(\`25년, \`26.03).
- 대필 시 한자 한 글자 축약(要·必·可·難)은 풀어 쓴다: 「~해야 함」「~가능함」.
- 한국에서 잘 안 쓰는 한자어를 끼워 넣지 않는다.
- 출처는 주어 앞에 세운다: 「시장조사기관 Omdia에 따르면」「ITU의 EAI는」.
- 근거 위계: 표준기관·정부 공식문서 > 시장조사기관 > 언론.

## 5. 비유

낯선 개념에는 친숙한 비유를 쓰되, 비유와 실제 작동 방식이 어디서 다른지 한 줄로 밝힌다. 비유를 사실의 근거로 쓰지 않는다.

## 6. 장 유형별 양식

### 6-1. 시사점 슬라이드
| 요소 | 규격 |
|---|---|
| 제목 | `N. {주제} 시대 {분야} 변화 시사점` 빨강 bold |
| 헤드라인 | 1문장에 **비교 대상 명시**(「AI 에이전트는 사람과 다르게 일한다」), 2문장은 두 변화를 병렬 열거 후 「{축}이 이제 「A」→「B」로 전환될 것임」으로 닫음 |
| 열 제목 | 밑줄 굵은 검정 3개: `관점` / `{주제}로 전환 시 동반되는 변화` / `{분야} 변화 요구 사항` |
| 좌측 라벨 | 회색 박스 3축 |
| 본문 셀 | 양쪽 열 모두 `A → B` 이동으로 리드, 오른쪽 셀은 메커니즘(왜 그렇게 됐나)을 앞세움, 서브 불릿 2개 이내 |
| 하단 | ☞ 결론줄·※ 단서줄·Source 줄 없음 |

### 6-2. 비주얼 요약 슬라이드
- 상단 대형 제목(빨강) → 좌 As-Is / 우 To-Be 2분할 전면 도해 → 가운데 `A < B` 판정 한 줄 → 각 열 하단 설명 3줄 → 하단 전폭 결론 띠(흰 글씨, 이 띠만 `~합니다`).
- 색: As-Is·기존 요소 회색, To-Be·핵심 변화 빨강, 보조 강조 적갈색.

### 6-3. 일반 분석 장
- 상단: 결론 헤드라인(2문장형 권장).
- 하단: 표·도식·막대·타임라인·2×2 중 내용 유형에 맞는 것 하나(`../../generate-full-report/references/visual-catalog.md` 참고).
- 수치 밀집 장은 하단에 Source 줄.

## 7. 논증 태도

- 좋은 소식 뒤에는 단서를 붙인다(「하지만 Gap이 큼」).
- 쟁점은 온전한 의문문으로 던진다(「물건이냐, 흐름이냐?」).
- 기술 설명에서 멈추지 않고 사업 모델·경제성으로 착지한다.
- 미국·중국·유럽 대비로 한국의 위치를 묻는 구도를 즐겨 쓴다.
