# 덱 규칙 (image-deck)

> 1920×1080 이미지 슬라이드의 측정값, 문장 규칙, 색 의미, QA 점검표, 겪은 문제와 대응
> 수치는 `deck_core.py` 의 CSS 와 같음. 바꾸려면 코드와 이 문서를 함께 고침

## 2. 헤드라인 규칙

- 명사형 종결(~임, ~음, ~함). 「~입니다」체 쓰지 않음(비주얼 요약 결론 띠만 예외)
- 1~2문장, 90~130자, 2줄 이내. 숫자 2개 이상
- 1문장 = 무엇이 어디에 몇 개(사실·구조), 2문장 = 그래서 어떻게 봐야 하는가(분석 덱) 또는 보완 사실(현황 덱, 판정 없음)
- 제목형 명사구로 끝내지 않음. 헤드라인만 읽어도 판단이 서야 함
- 「」 는 자기가 세운 개념·명제에만. ☞ 는 헤드라인에 쓰지 않음

## 3. 본문 규칙

- 산문 단락 금지 : 160자가 넘는 글 덩어리는 QA 경고. 컴포넌트로 쪼갬
- 글자 19px 이상(계산된 크기 기준, 그림 안 글자 포함)
- 한 섹션(파트) 안에 컴포넌트 3종 이상. 표만 있는 쪽 3장 연속 금지(덱 QA 경고)
- 표 8행 이하. 넘으면 쪽을 나누거나 `hbars`·`cards` 로 바꿈
- 본문 쪽 절반 이상에 ☞ 정리 줄(`callout`) 한 줄. 헤드라인을 되풀이하지 않고 그 쪽의 셈·대비를 한 줄로
- 숫자는 원고(MD) 값 그대로. 렌더 전에 원고에 그 숫자가 있는지 확인. 계산한 값은 `note` 에 계산식을 적음
- 날짜 : 덱은 `2026.10.12`, `2026.10`. 하이픈 날짜(2026-10-12)는 QA 경고
- 줄표(U+2014) 쓰지 않음(QA 경고). 콜론, 쉼표, 괄호로 바꿈
- 쪽 아래 빈 공간이 본문 높이의 30% 를 넘으면 QA 경고 : `fill()` 로 묶음 사이를 벌리거나 `row_height`, `height`, `bar_height` 로 컴포넌트를 키움

## 4. 색 의미 (덱 전체에서 고정)

| 토큰 | 기본값 | 뜻 | 쓰는 곳 |
|---|---|---|---|
| `accent` | #D42020 | 구조 표시 | 섹션 라벨, 위·아래 선, 간지 현재 행 |
| `inside` | #A31D1D | 관내(범위 안, 주 대상) / 강조 | 칩, 수치 타일, 막대 기본색 |
| `outside` | #1A3A6B | 관외(범위 밖, 비교 대상) / 기준 | 칩, 비교 기준 막대, 계층 기본색 |
| `unknown` | #8A8A8A | 미확인 | 점선 칩, 회색 타일 |
| `key` | #C00000 | 핵심 변화 / To-Be | 비주얼 요약, 시사점 제목, 핵심 사건, ☞ 표시 |
| `aux` | #843C0C | 보조 강조 | 시사점 불릿, 도해 보조 요소 |

- 같은 색에 다른 뜻을 겹쳐 쓰지 않음. 범례 없이 색만으로 뜻을 전하지 않음(칩 글자, 열 머리 꼬리표로 함께 표시)
- 바꿀 때는 `make_theme({...})` 를 쓰고 `check_palette()` 로 다시 확인

## 5. 팔레트 검사 기준 (`check_palette`)

| 검사 | 기준 | 결과 |
|---|---|---|
| WCAG 2.x 대비 | 24px 미만 글자 4.5 이상, 24px 이상 굵은 글자 3.0 이상 | 미달이면 FAIL(덱 QA 오류) |
| 의미색 구분 | 관내·관외·미확인, As-Is·To-Be·보조 강조 묶음 안 쌍마다 CIE76 ΔE 20 이상 | 미만이면 WARN |
| 적록색약 모사 | Machado·Oliveira·Fernandes(2009) deuteranopia 행렬(선형 RGB)을 거친 뒤 ΔE 10 이상 | 미만이면 WARN |

- 검사 대상은 CSS 에서 실제로 쓰는 글자색·바탕색 쌍 57개(각 쌍의 가장 작은 글자 크기 기준)
- 간지에서 일부러 흐리게 한 비활성 행 글자(`dim`)는 장식으로 보고 대비 검사에서 뺌
- 기본 팔레트 결과 : FAIL 0, WARN 0. 여유가 가장 적은 쌍은 「사분면 강조 칸 이름」 3.09(기준 3.0), 「To-Be/보조 강조」 적록색약 ΔE 12.9(기준 10)

## 6. 자동 QA (`render_all`)

| 구분 | 검사 | 수준 |
|---|---|---|
| 쪽 | 본문 넘침(scrollHeight > clientHeight + 2), 가로 넘침 | 오류 |
| 쪽 | 도해·타임라인·사분면·막대·계층 영역 넘침(`qa-fit` 표식 요소와 그 안의 잘리는 요소) | 오류 |
| 쪽 | 헤드라인 3줄 이상, 출처 3줄 이상, 섹션 라벨과 소제목이 한 줄에 안 들어감 | 오류 |
| 쪽 | 이미지 로드 실패(naturalWidth == 0), 19px 미만 글자(HTML 글자만, `chart_img` 그림 안 글자는 육안 확인), 쪽 밖으로 나간 글자 | 오류 |
| 쪽 | 출처 줄과 본문 겹침, 프로필 플레이스홀더(`{AUTHOR_KR}` 등) 잔존 | 오류 |
| 쪽 | 글자 자동 축소, 사분면 이름 겹침, 표 9행 이상, 막대 11개 이상, 시사점 칸 불릿 3개 이상 | 경고 |
| 쪽 | 본문 아래 빈 공간 30% 초과, `fill` 묶음 사이 빈 공간 22% 초과, 160자 넘는 글 덩어리 | 경고 |
| 쪽 | 줄표, 하이픈 날짜, 금지어(lexicon.json 을 찾으면) | 경고 |
| 쪽 | 비주얼 요약·시사점 쪽에 ☞ 줄이나 Source 줄 | 경고 |
| 덱 | 팔레트 대비 미달 | 오류 |
| 덱 | 표만 있는 쪽 3장 연속, 섹션 안 컴포넌트 3종 미만, ☞ 쪽 절반 미만, 한글 글꼴 없음 | 경고 |

- 컴포넌트 판별은 각 컴포넌트 최상위 요소의 `data-c` 표식으로 함(`stats`, `cards`, `mini_table`, `flow`, `chip`, `callout`, `note`, `chart_img`, `hbars`, `timeline`, `quadrant`, `layers`, `implication`). `callout`·`note`·`chip` 은 종류 셈에서 뺌
- 직접 쓴 HTML 조각도 최상위 요소에 `data-c="이름"` 을 붙이면 종류 셈에 들어감
- 결과 : 콘솔 표 + `qa_report.json`(쪽별 종류·섹션·컴포넌트·헤드라인 줄 수·출처 줄 수·본문 아래 빈 공간·오류·경고·쪽 글, 덱 오류·경고, 팔레트, 글꼴)
- 금지어 사전은 `../generate-full-report/references/lexicon.json` 또는 `../report-harness/references/lexicon.json` 을 찾아 씀(경고만). 현황 덱은 `mode="status"` 로 평가어도 경고

## 7. QA 점검표 (렌더 뒤 사람이 보는 것)

- [ ] `render_all` 오류 0
- [ ] 경고는 하나씩 읽고 고치거나 남길 이유를 적음
- [ ] PNG 를 한 장씩 열어 겹침, 잘림, 넘침, 어색한 빈 공간이 없는지 봄(자동 QA 는 겹친 상자 모양까지는 다 잡지 못함)
- [ ] 숫자를 원고와 대조(특히 막대 값 라벨, 수치 타일, 표)
- [ ] 같은 이름의 표기(회사, 기관, 외국 이름)가 쪽 사이에서 같음
- [ ] 색 의미가 쪽마다 같음(관내 빨강, 관외 네이비, 미확인 회색)
- [ ] 표지·감사 쪽 작성자 정보가 프로필 값과 같음
- [ ] 묶기 뒤 PDF·PPTX·zip 쪽 수가 PNG 수와 같음(`bundle` 이 대조하고 다르면 오류)

## 8. 겪은 문제와 대응

| 문제 | 원인 | 대응 |
|---|---|---|
| 한글이 네모로 나옴 | 시스템에 한글 글꼴 없음 | Noto Sans CJK KR 설치. QA 머리줄의 「글꼴」 항목과 `qa_report.json` 의 `fonts` 로 확인 |
| 「」 앞뒤가 넓게 벌어짐 | CJK 괄호의 전각 여백 | 본문 전체에 `font-feature-settings:"halt"` 를 켬(괄호·쉼표류만 반각, 한글 폭은 그대로) |
| 출처가 2줄이 되며 본문과 겹침 | 출처 줄이 고정 위치 | 출처 줄을 아래 기준으로 놓고, 겹치면 본문 높이를 자동으로 줄임(줄인 만큼 넘치면 QA 오류) |
| 사분면 점 이름이 겹침 | 점이 가까움 | 렌더 때 이름 자리를 r·l·t·b·대각선 순서로 옮겨 봄. 못 피하면 경고 → 점 이름을 줄이거나 `quadrant` 높이를 키움 |
| 도해 상자 글자가 넘침 | 상자 크기 고정 | 19px 까지 자동 축소 + 경고. 그래도 넘치면 오류 → 글을 줄임 |
| 짧은 판정 「A < B」 가 1px 줄어듦 | 판정 줄 높이와 글꼴 줄 높이 차이 | 판정 줄은 기본 줄 높이를 쓰고 부호만 1.1배 |
| 카드 안 칩 높이가 들쭉날쭉 | 형제 요소 여백 규칙이 인라인 칩에도 걸림 | 형제 여백은 블록 요소(div, table)에만 줌 |
| 쪽 아래가 비어 보임 | 컴포넌트가 짧음 | `fill()`, `row_height`, `hbars(height=)`, `layers(height=)` 로 높이를 나눠 씀 |
| 예전 PNG 가 섞여 묶임 | 쪽 수가 줄었는데 예전 파일이 남음 | `render_all` 이 같은 접두어의 예전 `sNN.png/html` 을 지우고 다시 씀 |
| 투명 PNG 가 PDF 에서 검게 보임 | 알파 채널 | `bundle` 이 투명 PNG 를 흰 바탕으로 펴서 넣음 |
| 콘솔에서 한글 출력 오류 | UTF-8 이 아닌 콘솔 | 출력 스트림을 `errors="replace"` 로 바꿔 멈추지 않게 함 |
| 작업 공간이 초기화되어 파일이 사라짐 | 세션 컨테이너 교체 | 단계마다 PNG 묶음과 `spec.py` 를 사용자에게 전달해 둠 |
