# {대상} {시리즈} : 조사 공통 브리프 (D1~Dn)

> 이 파일은 뼈대임. 오케스트레이터가 `{ }` 를 채워 작업 폴더에 `BRIEF.md` 로 두고, 조사 에이전트에게는 「`BRIEF.md` 를 처음부터 끝까지 읽고 그대로 따를 것. 담당은 D{n}」 한 줄만 줌
> {시리즈} · {대상} 편 · 단계 : {현황 / 분석 / 진단 / 제언} · 조사 기준일 {YYYY-MM-DD}
> 예시 채움 : 「가상의 B시 공공자전거 · 현황 · 조사 기준일 2026-09-30」

## 0. 제1 규칙

- {SKILL.md 1절 원칙 가운데 이번 단계에 걸리는 것을 그대로 옮김}
- 현황 단계면 : 있는 것, 이어진 것, 문서에 적힌 것만 적음. 판정, 평가, 제언, 점수, 등급을 쓰지 않음
- 기억(사전지식)의 수치, 날짜, 이름은 원문을 열어 확인하기 전에는 쓰지 않음. 못 찾으면 추정하지 말고 「미발견」으로 적음
- 「없음」에는 조사 범위를 붙임 : 「이번 조사 범위에서 문서 미발견」. 「문서 미기재」는 문서가 그 내용을 적지 않았다는 뜻이지 그 일이 없다는 뜻이 아님

## 1. 범위

| 항목 | 이번 편 |
|---|---|
| 경계 | {지역 경계, 사업부, 기간 등. 최근 바뀐 경계는 검색으로 먼저 확인} |
| 안에 둘 것 | {대상 목록} |
| 밖에 둘 것 | {인접 대상. 「밖」으로 표시하고 안의 셈에 넣지 않음} |
| 다루지 않을 것 | {이번 단계 밖의 주제} |

## 2. 도구와 출처

- 도구 : WebSearch, WebFetch 만 씀. 셸 명령으로 URL 을 받아 오지 않음
- 검색 예산 : 갈래당 검색 {30}회 안팎. 공식 사이트와 이미 아는 URL 은 검색하지 않고 바로 열람함 (세션 전체 검색 한도를 갈래 수로 나눈 값. 한 갈래가 예산을 다 쓰면 다른 갈래가 못 찾음)
- 출처 순서 : 1차(공식 사이트, 공시, 정부·기관 원문, 표준기관) → 2차(언론, 업계 자료) → 기타(위키, 기업정보 사이트, 재게재). 2차 이하만 있으면 「2차」 태그
- 행마다 : 출처 이름, 발행일, URL, 열람일, 태그
- 금액 : 층위(계획, 예산안, 선정, 집행, 총사업비, 재원별)를 문장에 적음. 통화는 바꾸지 않음. 기준이 다른 숫자는 한 문장에서 비교하지 않음
- 날짜 : MD 에서는 `YYYY-MM-DD`

| 태그 | 뜻 |
|---|---|
| 「단독」 | 출처 1곳 |
| 「상충」 | 출처마다 값이 다름. 둘 다 적고 출처를 각각 붙임 |
| 「미확인」 | 원문을 열지 못함 |
| 「2차」 | 원문이 아닌 재게재, 요약, 위키 |
| 「(계산)」 | 원문 값으로 직접 셈. 식을 함께 적음 |
| 「문서 미발견」 | 조사 범위에서 문서를 찾지 못함 |
| 「문서 미기재」 | 문서는 있으나 그 항목을 적지 않음 |

- 「」 안에는 원문 문장만 넣음. 요약이나 의역은 「」 밖에 씀
- 개인 이름과 개인 연락처는 적지 않음(기관, 회사, 국가 이름만)
- 「표준」 「원칙」은 누구의 것인지 적음(어느 기관의 어떤 문서인지)

## 3. 산출

- 파일 : `research/D{n}_{갈래이름}.md`
- 문체 : 명사형 종결(~임, ~음, ~함), 표 위주
- 순서
  1. 한 줄 요약
  2. 담당 절 (표 : 항목 | 값 | 출처 | 날짜 | URL | 태그)
  3. 상충 목록 (값 A, 출처 A / 값 B, 출처 B)
  4. 접근하지 못한 원문 (URL, 이유)
  5. 검색·열람 로그 (검색어 목록, 연 URL 수)

## 4. 최종 메시지 (오케스트레이터에게)

- 파일 경로
- 한 줄 요약
- 핵심 셈 5개 (값과 출처)
- 원문으로 확인한 것과 2차 출처에만 있는 것의 구분
- 상충과 미발견 항목
- 검색 {n}회, 열람 {n}건
