# {대상} {단계} 독립 검토 브리프 (R1~Rn)

> 이 파일은 뼈대임. 오케스트레이터가 `{ }` 를 채워 작업 폴더에 `REVIEW.md` 로 둠
> 검토 에이전트에게는 「`REVIEW.md` 를 처음부터 끝까지 읽고 그대로 따를 것. 담당은 R{n}」 한 줄만 줌
> 검토자는 검토 대상을 만들지 않은 에이전트여야 함(자기 편애를 막기 위함)

## 0. 검토 대상과 기준

| 담당 | 검토 대상 | 대조 기준 |
|---|---|---|
| R1 | {예) MD 토의본 §1~§3} | {research/D1~D3_*.md, 2차 검증 결과} |
| R2 | {예) Word content_ch1.py, content_ch2.py} | {확인된 MD 토의본, claims.json} |
| R3 | {예) 덱 P1~P2 PNG} | {확인된 MD 토의본} |
| N1 | 수치 독립 재계산 | {원값 표 : 오케스트레이터가 이 브리프에 직접 붙임} |

## 1. 볼 것

1. 사실 : 값, 날짜, 이름, 단위, 금액 층위가 기준 파일과 같은지
2. 출처 : 수치마다 출처가 있고, 그 출처에 실제로 그 값이 있는지(태그 「단독」 「2차」 가 맞게 붙었는지)
3. 계산 : 「(계산)」 값과 비율, 증감률, 합계가 맞는지
4. 규칙 : 단계 규칙(현황 단계의 평가어, 제언 금지 등), 금지어, 날짜 형식, 줄표, 가리킴
5. 안의 모순 : 같은 값이 절마다 다르게 쓰였는지, 요약과 본문이 어긋나는지
6. 빠진 것 : MD 에 있는 채택값이 산출물에서 빠졌거나, MD 에 없는 사실이 산출물에 들어왔는지

## 2. 고치는 규칙

- 확인한 오류만 고침. 기준 파일로 확인하지 못한 것은 고치지 않고 「확인 요청」으로 적음
- 최소 수정 : 틀린 값, 틀린 말만 바꿈. 문체 취향이나 구성은 바꾸지 않음
- 고친 곳은 모두 표로 남김 : 위치 | 전 | 후 | 근거(기준 파일과 줄)
- 원고(.py, .md)를 고쳤으면 selfcheck 를 다시 돌려 PASS 를 확인함

## 3. 수치 독립 재계산 (N1)

- 산출물 숫자를 믿지 않음. 오케스트레이터가 붙인 원값으로 자기 스크립트를 써서 처음부터 다시 셈
- 비율, 증감률, 합계, 평균, 단위 환산을 모두 다시 셈. 반올림 규칙은 산출물과 같게(소수 첫째 자리 등)
- 결과 표 : 항목 | 원값 | 다시 센 값 | 산출물 값 | 같음/다름

| 원값 (오케스트레이터가 채움) | 값 | 출처 |
|---|---|---|
| {예) 2025년 연간 대여} | {1,284,300} | {출처} |
| {예) 2024년 연간 대여} | {1,102,500} | {출처} |

## 4. 최종 메시지

- 고친 곳 표(건수)
- 확인 요청 목록(고치지 않은 것과 이유)
- 다시 돌린 selfcheck 마지막 줄
- 미해결 0 이 아니면 「NEEDS_REVIEW」 와 남은 항목
